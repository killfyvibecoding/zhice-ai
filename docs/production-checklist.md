# 生产发布检查清单

## 必须完成

- [ ] 使用 HTTPS 公网域名，配置微信合法域名。
- [ ] 配置生产 `AUTH_SECRET`、数据库、AI 和图片服务 Secret。
- [ ] SQLite 改为 PostgreSQL 或配置可靠备份。
- [ ] 上传文件迁移到对象存储，并限制类型、大小和生命周期。
- [ ] 为 AI、上传、登录、导出和分享接口配置限流、超时和错误告警。
- [ ] 关闭调试积分和开发 OpenID。
- [ ] 验证简历解析、简历优化、模板生成、职业照片、模拟面试、报告和导出链路。
- [ ] 检查日志脱敏，确保 Key、简历正文和照片不会被记录。
- [ ] 配置密钥轮换和数据库备份恢复演练。

## 商业化前补充

- [ ] 微信支付和订单回调。
- [ ] 积分账本、扣费幂等和失败退款。
- [ ] 用户协议、隐私政策、个人信息授权和 AI 内容提示。
- [ ] 客服、申诉、内容安全和数据删除流程。
